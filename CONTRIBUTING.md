Package overview: [levilabs.dev/open-source/nuxt-notify](https://levilabs.dev/open-source/nuxt-notify)

## Before you open a PR

1. Open an issue for larger changes so we can align on approach.
2. Run lint and tests from the module root:

   ```bash
   npm run lint
   npm test
   ```

3. For changes that affect the playground or Tailwind scanning, verify locally:

   ```bash
   npm run dev
   ```

4. Follow existing code style (ESLint is configured in this repo).

## Security issues

Do **not** open a public issue for vulnerabilities. See [SECURITY.md](SECURITY.md).
